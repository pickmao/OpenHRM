# 知事识人操作教程

[下载 Word 教程](./知事识人填报归集实操教程.docx)

2026年11月8日更新为 Excel 表格版，共15页，包含12幅操作截图及评分单元格局部图。

教程包括宽屏填写、附件4人数及评价、附件5按年度记录工作与多名参与人员、附件6和附件7逐列评分、考察组谈话录入、两张研判表的数据来源、退回重填及人工修订。

填写后保存草稿不参与归集；提交后按所属考察批次、材料年度、支部和人员身份归集到班子与干部研判。管理员需先在填报进度中关联研判期间。评分缺少必要来源时保留缺项，干部谈话评分和综合排名口径仍需业务确认。

文中采用独立演示数据。线上入口为 [干部动态调整系统](https://zqxiaochengxv.xin)。
