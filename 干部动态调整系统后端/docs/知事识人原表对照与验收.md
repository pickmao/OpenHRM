## 客户确认的栏目衔接（2026-11-07）

客户说明，“知事识人”栏目通过填报各类收集表，为“分析研判”栏目完善最终的班子、干部研判表。目标流程为：下发和填报收集表 → 统计分数、归集述事及谈话材料，并读取花名册客观数据 → 汇入“领导班子研判”和“中层干部研判” → 考察组补充评语、核对后形成最终研判表。

| 环节 | 栏目及职责 | 提供给研判表的信息 |
|---|---|---|
| 表单收集 | “知事识人”负责表单下发、填写、回收和进度查看 | 附件 4 的班子基本情况与调整建议、附件 5 的年度述事、附件 6 的班子测评、附件 7 的干部测评等原始数据。 |
| 测评统计 | 汇总附件 6、7 的有效测评数据 | 分别形成班子和干部的测评分数，按已确认口径提供认可率和排名。 |
| 述事归集 | 提取附件 5 的重点工作、简要表述和人员贡献 | 按支部及年度提供班子干事评价的事例；干部个人贡献保留具体人员、承担角色、任务和作用，个人研判表的逐列对应仍待核对。 |
| 客观数据统计 | 从花名册读取对应成员资料 | 为班子表计算年龄、学历、任现职年限三组人数或统计值，并为个人研判提供相应基础资料。 |
| 谈话与考察组评语 | 录入现场面对面谈话材料，由考察组形成评语 | 补充能力评价、存在不足等文字研判内容，具体录入入口和原文保存方式待确认。 |
| 最终汇总 | “分析研判”中的“领导班子研判”“中层干部研判”承接上述数据和材料 | 完善两张分析研判情况明细表，供考察组核对和完成研判。 |

汇总时需要关联同一考察批次、材料年度、支部和具体干部。附件 1 的谈话测评、附件 2 的自评、附件 3 的个人述事也作为研判参考材料归集，具体字段对应随研判表核对结果补充。

本节记录客户要求的目标流程。后续验收需要检查收集表提交、统计后，数据和材料是否能够进入对应的研判记录，并可追溯到填报来源。

## 填报归集到研判记录（2026-11-07）

填报提交后，系统将已提交的数据写入“领导班子研判”和“中层干部研判”的对应期间记录。新建批次可勾选“提交后自动归集”并选择研判期间，已有批次可在“填报进度 → 归集到研判表”关联期间并归集已收数据。关联后，提交、退回和重新提交都会在同一事务中更新相应研判记录。

| 来源 | 班子研判中的目标 | 干部研判中的目标 |

| 花名册 | 按选定成员和截止日计算年龄、最高学历人数、任现职年限人数 | 姓名、单位、职务、年龄、学历、职称、参加监狱工作时间、任职年限、主要业务等基础信息 |
| 附件 4 | 人员配备、阅历结构人数、调整建议 | 作为来源材料查阅 |
| 附件 5 | 按实际年度写入干事评价，保留工作名称和简要表述 | 按花名册人员编号写入该年度工作、承担角色和具体贡献 |
| 附件 2、3 | 作为来源材料查阅 | 自评表中的健康、业务、奖惩、本人填写的机关及监区工作年限，以及个人述事中的主要表现 |
| 考察组谈话及研判记录 | 能力评价、存在不足，谈话原文保存在归集来源中 | 能力评估、存在不足、谈话研判原文及日期、谈话人员 |
| 附件 1 | 支部整表“其他情况”保存为可追溯的谈话材料 | 干部五维测评可在原表查看，具体评分公式待确认 |
| 附件 6、7 | 书记组按 20% 的贡献分、民警职工组均分、最终得分、待全部对象收齐后的班子排名；认可率按选定口径计算 | 七看评价分、工作认可度分；谈话评分、综合研判评分及综合排名保留待确认项 |
