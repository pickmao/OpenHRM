## 组织与人员

机关支部是多个部门的共同上级，例如生活卫生科、狱内侦查科的人员都属于机关第四党支部。监区及医院使用“支部 → 部门”的结构；已存在以监区名称命名的支部时复用它，避免创建第二套。

人员当前部门沿用花名册优先的既有规则，从部门向上查找支部。尚无可匹配花名册时使用有效组织成员关系。重名、部门无法唯一定位、缺少账号等情况保留为待维护，不凭照片创建账号。初始化组织不会补录人员或改变人员职务。

“政工”按工作联系人理解，不自动等同于书记、副书记或支委。书记身份仍使用有效的支部任职关系维护；照片中的姓名暂待核对，不直接赋予角色或权限。“纸质版”仅为报送提示，照片不足以确定具体表单、批次及完成状态，不能自动记为已提交。

## 与知事识人衔接

附件 1、4、5、6-2、7-4 沿用本支部范围；附件 6-1 面向全部支部；附件 2、3、7-1、7-2、7-3 沿用既有全局对象规则。支部归属用于确定人员范围，填报身份和统计权重继续按各附件规则计算。已下发任务保留当时对象快照；调整组织后，新预览和新任务使用新的归属。

## 系统入口

组织管理 → 支部管理 → 各支部参考清单。先显示 27 个单位及各部门的“已归属 / 纳入支部 / 新建并纳入”，点击“应用组织归属”后写入。

应用时复查全部清单，重复应用不会重复创建。若部门已有不同上级、同名无法唯一定位、组织已停用或将形成循环，则整批拒绝，保留当前组织数据。清单外的组织和部门归属不受影响。不自动合并近似名称，例如“勤务监区”与“警务监区”需要人工核对。

接口：GET /api/org/branches/reference-catalog/ 预览；POST 同一路径应用。查看需 orgs:view，应用同时需 orgs:create 和 orgs:edit，超级管理员可操作。不需要数据库结构迁移。
