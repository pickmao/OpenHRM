## 使用

打开 http://localhost:5173 。管理员账号 `demo_admin` 可以查看全部栏目，普通填报账号为 `demo01` 至 `demo12`。首次生成的密码由执行命令输出，不写入源码。任务和纪实按登录账号显示，原管理员的“我的任务”不会自动变成演示账号的任务。

演示管理员已分配所有 11 类知事识人待填表单，以及通用表单、匿名评价和推荐待办。浏览完整统计时选择带“完整统计样例 / 结果样例 / 统计样例”的关闭批次。

## 重复生成

在后端目录、已配置对应开发数据库的环境运行：

```powershell
python manage.py seed_demo_data
```

命令默认仅允许 DEBUG 开发环境，默认随机生成新账号密码，也支持 `--password` 参数。生产演示需先备份数据库，再显式指定 `--allow-production --password-stdin`，通过标准输入提供至少 12 位密码。该方式不会启用 DEBUG，也不会输出密码。固定 UUID 防止重复记录，不重置已有演示账号密码，不覆盖用户已经操作过的演示业务数据。真实数据不参与演示活动下发。数据库写入在同一事务内完成。

Excel 文件位于 `MEDIA_ROOT/forms/demo-v1/`，已有文件不覆盖。本机通过 `scripts/run-local.py` 使用 PostgreSQL 15432 端口；直接执行管理命令时需使用相同连接配置。
